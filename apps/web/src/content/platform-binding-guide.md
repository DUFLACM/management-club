> **公告**：三大网络赛平台（牛客 / Codeforces / AtCoder）的比赛数据，系统**按天自动同步**。绑定后无需手动上传成绩。

## 牛客：填写数字 ID

1. 登录 [牛客竞赛](https://ac.nowcoder.com/acm/contest/vip-index)，点击右上角头像进入**个人主页**；
2. 地址栏形如 `ac.nowcoder.com/acm/contest/profile/3224xxxx`，**最后那串数字**就是要填写的 ID。

![牛客个人主页地址栏中的数字 ID](/guides/nowcoder-uid.png)

## Codeforces / AtCoder：填写用户名

两个平台都直接填写你的**用户名（handle）**，不是邮箱。

以 AtCoder 为例：打开自己的主页，地址栏 `atcoder.jp/users/` 后面的部分就是用户名，填入后即可完成绑定。

![AtCoder 个人主页地址栏中的用户名](/guides/atcoder-handle.png)

Codeforces 同理：`codeforces.com/profile/` 后面的部分即用户名。

## 小提示

- 平台赛（牛客 / CF / AtCoder 的周赛、月赛）**报名前必须先绑定**对应平台账号，成绩按绑定账号从榜单自动计分；
- 绑定提交后由管理员核验，核验期间也可以先报名；
- 填错了可以在「我的」页面重新绑定。
